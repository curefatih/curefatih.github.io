About this project

Bugwise was a plug-and-play feedback and bug reporting platform that teams embedded on their sites with a single script. The product is no longer live; the demo and notes here reflect it as shipped. Visitors submit structured reports through a lightweight widget — with optional screenshots and screen recordings scoped to the active domain — while product teams triage everything from a React dashboard.

Similar submissions are grouped with OpenAI embeddings stored in PostgreSQL via pgvector, so recurring pain points surface as clusters instead of noise. Configurable alert thresholds notify teams by email when volume spikes. Integrations push approved items into GitHub issues and Trello cards, closing the loop between user signal and delivery work.

The stack is an Nx monorepo on the frontend (React, Vite, shadcn/ui, JSONForms builder) with a Go Fiber API, Redis-backed rate limiting, JWT auth, and Stripe subscriptions for tiered usage limits.
